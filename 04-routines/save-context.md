# Routine: Save Context

Use before compaction, a long-session exit, or a handoff to another agent.

Write a dated note in `08-memory-updates/` with:

- task and current state
- decisions and changed files
- commands run and verification result
- remaining risks and exact next step
- no secrets, tokens, raw environment files, or private data dumps

Read the saved note back before saying the handoff is complete.
