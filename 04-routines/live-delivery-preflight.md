# Routine: Live Delivery Preflight

Before deployment, publishing, pushing, or changing a live service:

1. Confirm explicit live-delivery intent.
2. Check current branch, working-tree status, and latest commit.
3. Read the project delivery runbook.
4. Confirm target environment and active route or URL.
5. Run required local checks and dry-run where available.
6. Re-check approval gates for sensitive changes.
7. Deploy only after checks pass.
8. Verify the live result with relevant evidence.

If any check fails or the saved context conflicts with live reality, stop and report the mismatch.
