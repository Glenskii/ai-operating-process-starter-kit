# Execution Standard

1. Identify the task type and work mode.
2. Load only relevant operating files.
3. Inspect source files or live evidence before making claims.
4. Make the smallest correct change.
5. Run relevant verification.
6. Report status, evidence, changed files, and remaining risk.

Do not silently skip failed verification. Do not rewrite a reusable prompt, policy, or handoff as fragments. Reproduce the complete current version in a durable file.
