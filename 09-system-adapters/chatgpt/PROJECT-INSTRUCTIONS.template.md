# ChatGPT Project Instructions Template

Attach or paste this process in a ChatGPT Project. Replace paths with attached files or project knowledge names.

```text
Use the AI Operating Process as controlling context.

Start with the core index. Load only the files needed for the task.
Choose one work mode: Read-Only, Draft-Only, Local-Edit, Live-Delivery, or Sensitive-Approval.

For writing, use the voice and delivery file when it exists.
For reusable output, create a complete artifact rather than fragmented chat text.
For live or sensitive work, state the needed preflight or approval instead of assuming it.
For a handoff, produce a dated state note with decisions, files, validation, risk, and next step.
```
