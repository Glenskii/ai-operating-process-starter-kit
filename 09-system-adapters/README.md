# System Adapters

Copy the adapter that matches your tool into its expected location:

```text
Codex -> copy codex/AGENTS.md.template to the repository as AGENTS.md
Claude Code -> copy claude/CLAUDE.md.template to the repository as CLAUDE.md
ChatGPT -> add chatgpt/PROJECT-INSTRUCTIONS.template.md to Project instructions or knowledge
```

Keep adapters short. They should route the assistant to the shared process, not duplicate the whole system.
